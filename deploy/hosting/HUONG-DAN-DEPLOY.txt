================================================================================
  3. CHI TIẾT TỪNG BƯỚC
================================================================================

  ─── 3.1. Đóng gói trên máy dev ───

  Chạy: deploy\hosting\package-for-deploy.bat

  Script tự động:
    • composer install --no-dev
    • npm run build (tạo public/build/)
    • Nén zip loại trừ node_modules, .git, .env

  Kết quả: deploy\ktnb-app-production.zip

  Nếu script lỗi, chạy tay:
    composer install --no-dev --optimize-autoloader
    npm ci
    npm run build
  Rồi upload toàn bộ project (có vendor/ và public/build/).

  ─── 3.2. Upload & cấu trúc thư mục ───

  Sau giải nén, cấu trúc trên hosting:

    ktnb-app/
    ├── app/
    ├── bootstrap/
    ├── config/
    ├── database/
    ├── deploy/
    ├── public/          ← Document Root TRỎ VÀO ĐÂY
    │   ├── index.php
    │   ├── .htaccess
    │   └── build/       ← JS/CSS đã build
    ├── resources/
    ├── routes/
    ├── storage/
    ├── vendor/
    └── .env             ← tạo từ env.production

  KHÔNG upload: node_modules/, .git/, .env từ máy local

  ─── 3.3. Document Root ───

  CÁCH ĐÚNG (khuyến nghị):
    Domain → /path/to/ktnb-app/public

  Nếu KHÔNG đổi được Document Root:
    • Copy deploy/hosting/htaccess-goc-project.txt → .htaccess (thư mục gốc)
    • Hoặc nhờ IT hỗ trợ

  ─── 3.4. Chạy post-deploy ───

  Linux / SSH:
    cd /path/to/ktnb-app
    chmod +x deploy/hosting/post-deploy.sh
    ./deploy/hosting/post-deploy.sh

  Windows hosting:
    deploy\hosting\post-deploy.bat

  Quyền ghi (Linux):
    chmod -R 775 storage bootstrap/cache

  Cron job (tùy chọn — import nền):
    Xem nội dung file deploy/hosting/cron-queue.txt
    Thêm vào cPanel → Cron Jobs

================================================================================
  4. CẤU HÌNH .ENV TRÊN HOSTING
================================================================================

  Tạo file .env từ mẫu: deploy/hosting/env.production

  ┌──────────────────┬────────────────────────────────────────────────────┐
  │ Biến             │ Giá trị production                                 │
  ├──────────────────┼────────────────────────────────────────────────────┤
  │ APP_ENV          │ production                                         │
  │ APP_DEBUG        │ false                                              │
  │ APP_URL          │ https://kiemtranoibo-ccks.ntt.edu.vn               │
  │ APP_KEY          │ Copy từ .env máy dev HOẶC php artisan key:generate  │
  │ DB_HOST          │ localhost (hoặc host hosting cấp)                │
  │ DB_DATABASE      │ Tên DB hosting                                     │
  │ DB_USERNAME      │ User DB hosting                                    │
  │ DB_PASSWORD      │ Password DB hosting (local để trống, hosting có)   │
  │ EXTERNAL_API_KEY │ Chuỗi bí mật mạnh, tự đặt (32+ ký tự)              │
  └──────────────────┴────────────────────────────────────────────────────┘

  SMTP / Email:
    Không cần MAIL_* trong .env cho quên mật khẩu & tin nhắn.
    Cấu hình trong: Cài đặt → Tham số hệ thống → tab Email (trên web).

  Password có ký tự đặc biệt:
    DB_PASSWORD="mat@khau#123"

  Sau khi sửa .env:
    php artisan config:clear
    php artisan config:cache

  6. IMPORT DỮ LIỆU TỪ MÁY LOCAL
================================================================================

  Trên máy dev (Windows), export MySQL:

    mysqldump -u root congcukiemtranoibo > backup.sql

  Trên hosting:
    • phpMyAdmin → chọn database → Import → chọn backup.sql
    • Hoặc SSH: mysql -u USER -p DB_NAME < backup.sql

  Nếu database mới (không import):
    php artisan migrate --force
    php artisan db:seed          (nếu cần dữ liệu ban đầu)

================================================================================
  7. CÂU HỎI THƯỜNG GẶP
================================================================================

  Q: Local không password MySQL, hosting có password — sửa đâu?
  A: Chỉ file .env trên hosting, dòng DB_PASSWORD=...

  Q: Có tự nhận localhost vs hosting không?
  A: Không. Máy dev dùng .env local; hosting dùng .env riêng.

  Q: Có cần npm trên hosting không?
  A: Không. Build sẵn public/build/ trước khi upload.

  Q: Có cần subdomain không?
  A: Không. Cùng domain, đổi Document Root vào public/

  Q: Lỗi 500 sau deploy?
  A: Kiểm tra quyền storage/, bootstrap/cache/
     Xem storage/logs/laravel.log
     php artisan config:clear

  Q: Trang trắng / không có CSS?
  A: Thiếu public/build/ → chạy npm run build rồi upload lại
     Hoặc Document Root chưa trỏ đúng public/

  Q: Không có SSH?
  A: Nhờ IT chạy post-deploy.sh
     Hoặc dùng Terminal trên cPanel (nếu có)
